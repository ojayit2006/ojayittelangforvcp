# Ojayit Telang — For Vice Chairperson, CSI SPIT

This is my campaign site for the Vice Chairperson selection at CSI SPIT
(Sardar Patel Institute of Technology), 2026.

I built it because I wanted the campaign to be something people could
actually read and check, rather than a poster and a few stories. Every
claim on the site is tied to work I have already done, and the budget
page publishes the real numbers behind the SPIT Hackathon instead of
summarising them.

## What's on the site

| Page | What it covers |
| --- | --- |
| Home | Who I am and what I'm running for |
| Motivation | Why I'm running, in my own words |
| Why Me | My experience timeline and the case for my candidacy |
| Vision | The committee structure I'm proposing and the five improvements I want to make |
| Budget | The full itemised SPIT Hackathon budget, published openly |
| Testimonials | Quotes from people I've actually worked with |
| Feedback & Donations | A feedback form and a way to support the campaign |

## Running it locally

```bash
npm install
npm run dev
```

Then open <http://localhost:3000>.

## Built with

Next.js (App Router), React, TypeScript, Tailwind CSS, and Framer Motion.
All campaign copy lives in `data/content.ts` so it can be edited in one
place without touching components.
